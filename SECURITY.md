# Security policy

Report vulnerabilities through GitHub's private vulnerability reporting (Security tab → "Report a vulnerability"), not in a public issue.

Include the touchid-gate commit, the macOS version, and steps to reproduce. The [README](README.md#security-model) and [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#3-threat-model) list the limits the project knows about; a report that bypasses one of the "yes" rows in the threat model is the most useful kind.
